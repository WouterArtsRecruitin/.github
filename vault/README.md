# Recruitin Vault — Centraal Register

> Eén plek voor al je prompts, MCP configs, scripts, workflows en templates.
> Nooit meer kwijtraken.

## Hoe het werkt

Elke keer dat je iets nieuws bouwt met Claude, wordt het automatisch hier geregistreerd. Je hoeft zelf niks te doen — Claude doet het via de instructies in `CLAUDE.md`.

| Map | Wat erin staat |

| [`workflows/`](workflows/) | GitHub Actions workflow templates |
